## 2. 求矩适线法：完整流程（已核实 ✅）

来源：土木在线《桥梁设计洪水流量推算的求矩适线法》（2024-06）+ 科普中国配线法词条（引《工程水文与水利计算》）+ CSDN 适线实操指南。与规范 6.2.5"求矩适线法"对应。

1. 收集洪水资料，必要时插补延长；按连序/不连序系列计算每个洪水的经验频率
2. 矩法计算平均流量 Q̄ 和变差系数 Cv（**Cs 不直接算**——抽样误差太大，按经验取 Cv 的倍数假定）
3. 假定多个 Cs（如 4Cv、5Cv、6Cv、7Cv），绘制多条理论频率曲线，与经验点据对比，目估或误差函数选最优；误差均大时可微调 Cv
4. 采用值代入 `Qp = Q̄(1 + Φp·Cv)` 查 Φ 表计算设计流量

**适线实操要点（工程经验，来自 CSDN 实操指南）**：
- 适线时以矩法估计值为初值，重点保证**最大几年实测点据**吻合（直接影响校核洪水）
- 增大 Cs 会让曲线上端更弯（大流量端抬升）
- 样本短（<20 年）时矩法 Cs 偏差大，参考省水文手册的 Cs/Cv 经验比值
- 工程实际 Cs 常取 2~4 倍 Cv，取整倍数便于查 Φ 表

## 3. 不连序系列经验频率（特大洪水处理，已核实 ✅）

来源：土木在线算例。设考证期 N 年，特大洪水 a 项（其中实测期内 l 项），实测期 n 年：

**方法一（独立处理）**：
- 特大洪水：`PM = M/(N+1)`（M 为考证期内排序）
- 实测系列（含实测期内特大）：`Pm = m/(n+1)`
- 重复流量经验频率取小值

**方法二（条件概率）**：
- 特大洪水：`PM = M/(N+1)`
- 实测期一般洪水：`Pm = PM,l + (1 − PM,l) × (m − l)/(n − l + 1)`
  （PM,l 为实测期最后一个特大洪水的经验频率）

## 4. 软件测试基准算例（收集自公开资源）

### 算例 T1：教学题（n=10，有完整数据与标准答案 ✅）

某流域年最大洪峰流量系列（m³/s）：`1200, 850, 1500, 900, 1100, 1350, 700, 1000, 1400, 650`

- 均值 `Q̄ = 1065 m³/s`
- `Σ(xi−Q̄)² = 885350`；均方差 `σ = √(885350/9) = 313.64`
- `Cv = 313.64/1065 = 0.29`
- 假设 `Cs = 2Cv`，P=1% 时查 Kp 表 `Kp = 3.0`
- **`Q1% = 3.0 × 1065 = 3195 m³/s`**

来源：人人文库水文计算题库（renrendoc）。注意用模比系数 Kp：`Qp = Kp·Q̄`，与 Φ 表等价（`Kp = 1 + Φp·Cv`）。

### 算例 T2：适线案例（n=32，参数齐全）

某水文站 32 年最大洪峰流量，按大到小前几项 2450、2180、1930、1720、1580，最小 280：
- 均值 860、σ=520、`Cv = 0.605`
- 矩法 Cs≈1.35（偏差大，弃用），取省手册经验比值 2.5 → `Cs = 2.5Cv ≈ 1.51`（适线中微调至 1.5 便于查表）
- P=1%、Cs=1.5 时 `Φ ≈ 3.33` → **`Q1% = 860×(1+0.605×3.33) ≈ 2593 m³/s`**
- P=0.1% 时 Φ≈4.58 → 校核洪水 ≈ 3240 m³/s

来源：CSDN 博客《水文频率分析中 Cv 与 Cs 参数估算及适线法实操指南》。

### 算例 T3：不连序系列完整算例（30 年实测 + 200 年考证期）

某水文站 1958–1987 年（n=30）实测洪峰流量；历史调查：考证期 200 年，最大 1903 年、第二 1921 年；1956 年为近 50 年第一位（200 年内序位不明）。特大洪水 a=5（1903、1921、1956、1981、1963），实测期内 l=2（1981、1963）。
- 经验频率按方法一/方法二分别计算后取值
- 适线结果：**`Q̄ = 5173.6 m³/s`，`Cv = 0.331`，`Cs = 6Cv = 1.99`**（目估理论曲线与经验点吻合最好）
- P=1%、Cs=1.99 时 `Φ = 3.604`
- **`Q1% = (3.604×0.331+1) × 5176.6 = 11345 m³/s`**

来源：土木在线。⚠️ 30 年逐年流量数值表为图片未提取，需要时从原帖截图录入或换用教材例题。

### 算例 T4：真实工程参数（达板水电站）

洮河李家村水文站 1947–2001 年（54 年）径流系列，矩法初估 + P-Ⅲ 适线：`Q̄=135 m³/s，Cv=0.32，Cs=2.5Cv`；红旗站 `Q̄=155，Cv=0.34，Cs=2.5Cv`。
来源：bodocs.net 工程文档。用于检验"矩法初估→适线采用"流程的真实工程参数量级。

## 6. Cs 与 Cv 的关系（工程惯例汇总 ✅）

- 规范/教材认可做法：矩法初估 Q̄、Cv，Cs 按经验倍比假定后适线调整
- 常用倍比：`Cs = (2~4)Cv`（配线法词条）；实际工程见 `2Cv`（教学题）、`2.5Cv`（达板电站）、`6Cv`（土木在线算例，特大洪水系列）
- 软件交互：Cv 连续滑块 + Cs/Cv 倍比选择（1~8 倍）或直接输入，实时重绘
