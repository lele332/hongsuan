    数据来源与出处¶

    JTG C30—2015《公路工程水文勘测设计规范》¶

    交通运输部政府信息公开网全文 PDF（126 页，扫描版）。第 6/7/8 章条文与系数表经渲染 OCR 定位后核对。

    https://xxgk.mot.gov.cn/2020/jigou/glj/202006/P020240607596475014848.pdf

    JTG C30—2015 完整版（含附录 A~E）¶

    附录 C 墩形系数及墩宽计算（12 种墩形，P73~76）与附录 D 岩石地基桥墩冲刷及基底埋深（P77~78）由完整版 PDF 渲染读图提取，编号 11/12 公式经第三方规范库文本交叉验证。

    JTG/T 3365-02—2020《公路涵洞设计规范》¶

    交通运输部公告 2020 年第 88 号附件（中国政府网公开全文 PDF，118 页文字版）。附录 B 全部水文查表由此提取。

    https://www.gov.cn/zhengce/zhengceku/2020-11/20/content_5562849.htm

    提取与校验脚本¶

    extract_appendix_b.py（表 B-9）· extract_aux_tables.py（B-5/B-6/B-8/B-10~B-14）· ocr_spec_pages.py（扫描版章节 OCR）· gen_*_ts.py（生成内置数据模块）。

    外部算例互证¶

    公式结构与系数经公开工程算例与期刊论文所引规范公式交叉验证（桥孔 154.16 m / 23.52 m 两例；冲刷冲止流速闭合校验）。
