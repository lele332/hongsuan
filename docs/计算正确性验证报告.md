## 二、架构论证：Φ 为什么这样算

软件采用的数学关系（`src/core/phi.ts`）：

```
Cs > 0 时：Φ = (Cs/2)·(G − α)，G ~ Gamma(α, 1)，α = 4/Cs²
水文频率 p 为超过概率 → 取 Γ 分布下侧分位数 1−p
Cs = 0 时：Φ = 标准正态分位数
Cs < 0 时：镜像 Φ(Cs, p) = −Φ(−Cs, 1−p)
```

**正确性论证（三步）**：

1. **均值**：E[Φ] = (Cs/2)(E[G] − α) = (Cs/2)(α − α) = 0 ✓（标准化变量均值应为 0）
2. **方差**：Var[Φ] = (Cs/2)²·Var[G] = (Cs²/4)·α = (Cs²/4)(4/Cs²) = 1 ✓
3. **偏态**：Γ(α) 分布的偏度系数 = 2/√α = 2/(2/Cs) = Cs ✓，线性变换不改变偏度

即：该构造产生的随机变量恰好是零均值、单位方差、偏度 Cs 的 P-Ⅲ 标准化变量，与 Φ 的定义（离均系数）严格一致。

**可解析的特例（不依赖任何数值库的硬证据）**：Cs=2 时 α=1，Γ(1,1) 退化为标准指数分布，分位数有闭式解：
`Φ(p) = −ln(p) − 1`，故 Φ(1%) = ln(100)−1 = 3.60517、Φ(0.1%) = ln(1000)−1 = 5.90776。
软件输出与解析值完全一致（测试 `phi.test.ts` 第 8/9 项）。

## 三、验证矩阵（五层独立证据）

| 层 | 方法 | 样本 | 结果 | 判定 |
|---|---|---|---|---|
| V1 | **scipy 独立实现交叉**：同一 (Cs, p) 网格，JS 内核 vs `scipy.stats.gamma.ppf` | Cs 33 档 × P 19 档 = **627 点** | 最大误差 3.3e-9；<1e-6 占比 **100%** | ✅ |
| V2 | **解析恒等式自检**：Cs=2 全频率与指数分布闭式解、Cs=0 与正态分位 | 4+4 点 | 全部 <1e-10 | ✅ |
| V3 | **numpy 独立交叉**（矩法统计）：3 组序列（n=10/15/30） | 均值/σ/Cv/Cs 共 12 项 | 相对误差全部 <5e-12 | ✅ |
| V4 | **工程算例端到端**：算例 T2（Q₁%≈2593）、T3（Q₁%≈11345）、校核洪水 | 4 项 | 与公开算例基准一致（含公开资料自身笔误修正后） | ✅ |
| V5 | **权威 Φ 表抽验**：表A《工程水文学》第5版附表 + 表B 浙江暴雨图集附表 6-2 | 75 + 36 点 | 表B 36/36 命中（≤0.005）；表A 71/75（4 点偏差 0.006~0.010，见下） | ✅（含表值转录差异说明） |

另：单元测试 17 项全部通过（`app/test_output.txt`）。

**V1 的意义**：scipy 的 `gamma.ppf` 与 JS 内核是完全独立的两条实现路径（不同语言、不同算法、不同作者），两者在全工程参数域一致到 1e-6 以下，意味着**两者同时出同样错的概率可以忽略**。这是数值计算领域交叉验证的标准做法。

**V5 表A 4 个未命中点的分析**：

| 点 | 软件算得 | 表值 | 偏差 |
|---|---|---|---|
| Cs=0.1, P=70% | −0.5362 | −0.53 | 0.006 |
| Cs=0.3, P=0.001% | 5.1500 | 5.16 | 0.010 |

该 4 点在 V1 层（scipy）与软件一致（误差 <1e-6），故差异来源是**表值本身**——表A 取自网页转录（SCAU 共享文库 OCR），3 位小数表自带 ±0.005 舍入，叠加转录误差即此量级。对 Qp 的影响 <0.5%，工程无感。
