## 1. 项目定位（一句话）

面向学生与青年工程师的公路桥涵水文计算软件：**符合 JTG C30-2015 规范、白盒化教学式交互、现代化 UI**。区别于国产商业软件（黑盒、老旧、贵）与国际免费软件（HEC 系，不合中国规范）。

**首个开发模块：设计流量推求**（桥涵水文计算链的第一环：设计洪水 → 桥孔 → 壅水 → 冲刷 → 涵洞孔径）。

## 2. 已确认决策（2026-09-22 与卓庆确认）

## 5. 设计流量推求 · 知识体系（模块核心）

### 5.1 基本概念（术语 2.0.x ✅）

- **设计洪水**：工程正常使用条件下符合指定防洪设计标准的洪水
- **设计流量 Qp**：与设计洪水相应的**桥位断面洪峰流量**（m³/s）
- **设计水位**：与设计洪水相应的洪水水面高程（第 6.5 条，由水位—流量关系曲线反推）

### 5.2 方法决策树（按资料条件选路，软件按此组织向导）

```
桥位断面有水文站实测流量系列？
├─ 有（理想 ≥30 年，含历史洪水调查考证）
│    └─ 方法A：频率分析法（P-III 适线）          ← 规范 6.2 ★模块核心
│        （断面与站面积差 <20% 且 ≤1000 km² 时先做系列转换 6.2.2）
├─ 无实测，但有历史洪水调查（洪痕、文献）
│    └─ 方法B：历史洪水位法（曼宁公式 + 频率外推）  ← 规范 6.3
└─ 完全无资料
     └─ 方法C：地区经验公式 / 推理公式（F<100km²） ← 规范 6.4
          小桥涵/路基/特殊地区 → 按第 9~11 章专门方法（6.4.3）
```

规范 6.1.3 明确：**可采用多种方法，经分析论证后选用合理的成果**——软件应支持多方法并行计算 + 对比（方舟水文通即如此设计）。

### 5.3 方法 A：P-III 频率适线（规范 6.2，模块核心）

**流程八步（软件主流程）**：

1. **资料审查**（6.2.1 ✅）：同一洪水类型、独立随机、人为影响还原、首几项重点考证、系列**不宜少于 30 年**且应有历史洪水调查成果。→ 软件做输入数据合理性检查（如系列长度提示）。
2. **系列插补/延长/转换**（6.2.2 ✅）：断面与水文站面积差 <20% 且 ≤1000 km²、暴雨分布均匀、无分洪滞洪时，按面积比转换。
3. **经验频率**（6.2.3 ✅）：
   - 连序系列：`Pm = m/(n+1) × 100%`（m 为从大到小的序位）
   - 不连序系列（含特大洪水）两种处理（见 `参考资料\教材与例题资料.md` §3，已核实）：
     - 独立处理法：特大洪水 `PM = M/(N+1)`；实测系列 `Pm = m/(n+1)`；重复流量取小值
     - 条件概率法：实测期一般洪水 `Pm = PM,l + (1−PM,l) × (m−l)/(n−l+1)`
     （N 为考证期年数，a 为特大洪水项数，l 为其中出现在实测期内的项数）
4. **参数初估**（6.2.5 ✅）：可采用**求矩适线法、三点适线法、绘线读点补矩法**计算均值 Q̄、变差系数 Cv、偏态系数 Cs 的初算值。
   - 矩法公式（教材标准 ⚠️ 按高冬光《桥涵水文》核实）：
     `Q̄ = (1/n)·ΣQi`；`Ki = Qi/Q̄`
     `Cv = √[ Σ(Ki−1)² / (n−1) ]`（无偏）
     `Cs = n·Σ(Ki−1)³ / [(n−1)(n−2)]`（无偏，仅作初估）
5. **理论频率曲线**（6.2.4 ✅）：宜采用**皮尔逊 Ⅲ 型曲线**；特殊情况经论证可用其他线型。
6. **适线**（6.2.5 ✅）：点绘理论频率曲线与经验点据比较，不吻合则调整 Cv、Cs 直至基本吻合。工程惯例 Cs 取 Cv 的 2~4 倍整数倍试凑（⚠️ 惯例值）。
   - **软件的杀手锏交互**：海森机率格纸上经验点据 + 理论曲线实时联动，Cv/Cs 滑块拖动即时重绘。
7. **设计值**（6.2.6 ✅ 规范原式）：
   `Qp = Q̄ · (1 + Φp · Cv)`
   其中 Φp 为离均系数，由 Cs 和设计频率 p 查 P-III Φ 值表（或数值计算 Γ 分布分位数）。Qp 也可写为 `Qp = Kp·Q̄`，Kp = 1+Φp·Cv 为模比系数。
8. **合理性论证**（1.0.5 ✅）：与上下游、邻站、地区统计参数对比（均值、Cv 沿流域渐变规律）。

**数值实现要点**：
- Φp 求解 = P-Ⅲ 分布（三参数 Γ 分布）的分位数计算，JS 中用**不完全 Gamma 函数**数值反解，或内置 Φ 值表插值（教材附表，精度 0.01）
- 海森机率格纸：横坐标按标准正态分布变换（P=0.01%~99.9%），ECharts 自定义坐标轴实现
- 目估适线之外可加"优化适线"（最小二乘/绝对偏差最小），作为进阶功能

### 5.4 方法 B：历史洪水位法（规范 6.3）

1. **历史洪水流量**（6.3.1 ✅ 规范原式）：
   稳定均匀流河段（顺直、比降均一、断面规整）：
   `Q = Ac·vc + At·vt`，`vc = (1/nc)·Rc^(2/3)·I^(1/2)`，`vt = (1/nt)·Rt^(2/3)·I^(1/2)`
   （河槽/河滩分算；宽深比 >10 时水力半径 R 可用平均水深代替；n 为糙率、I 为水面比降）
   非均匀流河段用试算法推水面线（6.3.1-4）。
2. **经验频率**（6.3.2 ✅）：由老居民记述/文献考证定序位，按 6.2.3 公式计算。
3. **推算设计流量**（6.3.3 ✅）：
   - 历史洪水流量**不宜少于 2 次**；Cv、Cs 应符合地区分布规律
   - 多次历史洪水可在海森机率格纸上定出经验频率曲线时 → 按适线法求 Q̄、Cv、Cs
   - 定不出曲线时：参照地区资料选定 Cv、Cs，按 `Q̄Ti = QTi / (1 + ΦT·Cv)` 求平均流量（ΦT 为重现期 T 年的离均系数），再按 6.2.6 推算 Qp

### 5.5 方法 C：无资料地区（规范 6.4）

- **6.4.1（✅）**：无资料地区，可按**地区经验公式及水文参数**求算设计流量；**求算的设计流量应有历史洪水流量的验证**。
- **6.4.2（✅）**：汇水面积 **< 100 km²** 的河流，可按**推理公式**计算；公式中的参数和指数，采用**各地区编制的暴雨径流图表值**。
- **6.4.3（✅）**：小桥涵、路基及特殊地区的设计流量计算，尚应符合第 9~11 章。

具体公式形式（规范正文只给原则，公式细节出自教材《桥涵水文》/《公路设计手册·桥涵水文》分册 ⚠️ 待对照核实）：

**推理公式（水科院型，公路科研所采用）**：
`Qp = 0.278 · (ψ · Sp / τⁿ) · F`
- Sp：雨力（mm/h），查地区暴雨等值线图（按设计频率取值）
- τ：汇流时间（h）；n：暴雨衰减指数
- ψ：洪峰径流系数；F：汇水面积（km²）

**径流厚度法（公路科研所暴雨径流公式，小流域涵洞常用）**：
`Qp = φ · (h − z)^(5/3) · F^(2/3) · β · γ · δ`
- φ：地貌系数（按地形、汇水面积、主河沟坡度查表）
- h：径流厚度（mm）；z：植被或坑洼滞留的径流厚度（mm）
- β：洪峰传播流量折减系数；γ：降雨不均匀折减系数；δ：湖泊/小水库调节折减系数

**面积比拟法（6.2.2 同型，转换/比拟通用）**：
`Q设 = Q参 · (F设/F参)ⁿ`
- 面积修正指数 n（✅ 论文引规范）：大中河流 0.5~0.7；<100 km² 小河流 >0.7；面积差 ≤3% 时 n=1

### 5.6 相关但不属本模块（边界说明）

- **设计水位**（6.5 ✅）：由水位—流量关系曲线按 Qp 反推 + 水面比降换算到桥位断面；复杂河段试算法推水面线。→ 属后续"桥孔/桥面高程"模块输入。
- **设计洪水过程线**（6.6 ✅）：同倍比放大法，`kg = Qp/Q`（典型洪峰流量）。→ 远期。

## 6. 软件功能规格（设计流量模块 v1）

**输入**
- 方法 A：年最大流量序列（表格/粘贴导入）、特大洪水标记与考证期 N
- 方法 B：断面数据（河槽/河滩分界、糙率、比降）、洪痕水位与重现期
- 方法 C：汇水面积、沟长、坡度、地区参数（或查表内置）
- 公共：公路等级 + 构造物类型 → 自动带出设计频率（表 1.0.8）

**计算**
- 方法 A 全流程：经验频率 → 矩法/三点法初估 → 交互式适线 → Qp
- 方法 B/C 各自公式链；多方法并行 + 结果对比表

**输出**
- Word 计算书（docx.js）：方法与公式出处（"按 JTG C30-2015 式 6.2.6"）、参数表、适线图、结果汇总、声明"计算结果供学习参考，工程应用需注册工程师复核"
- 适线图（ECharts，海森机率格纸）

**白盒化设计（差异化核心）**
- 每个参数输入框旁：含义、单位、合理范围、越界警示
- 每步计算展开显示中间量（如各年的 Ki、(Ki−1)²）
- 内置教材例题：加载 → 对照手算结果 → 验证
